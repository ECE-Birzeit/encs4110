# Setup Guide

Set up the tools once, at home, before your first lab. The lab PCs already have everything installed.

| Guide | Used in | Hardware |
| --- | --- | --- |
| [Keil and Tiva Support](./keil) | Every experiment | None to install; the LaunchPad drivers are part of it |
| [Assembly Project](./assembly-project) | Experiments 1–4: ARM assembly | None, everything runs in the simulator |
| [Tiva LaunchPad Project](./tiva-project) | Experiments 5–10 | Tiva C LaunchPad (EK-TM4C123GXL) |

Start with **Keil and Tiva Support**, then make the project type your next experiment needs.
